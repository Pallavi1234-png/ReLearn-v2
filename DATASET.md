# Re:Learn datasets

| File | Source | Rows | Notes |
|---|---|---|---|
| `questions.csv`, `misconceptions.csv`, `interventions.csv` | supplied, unmodified | 120 / 64 / - | taxonomy of 64 misconceptions |
| `student_attempts.csv` | supplied, unmodified | 254 (124 wrong, 130 correct or no working; 64 classes) | simulated; working text *narrates* the mistake; **each class has exactly one wording** |
| `extension_distribution.json` | team-authored | 1 misconception, 2 questions | `EXT-` ids; the taxonomy has no distribution error |
| `generated_cases.csv` / `.jsonl` | team-generated by `app/datagen.py` (seed 7) | 88 | templated maths working, labelled |

## generated_cases schema
`case_id, group, question, student_steps (" | " separated), final_answer, gold_misconception_id, expected_status, mechanism, must_not_be`

`expected_status`: `diagnosed` (must be named `gold_misconception_id`), `correct` (no alarm), `insufficient` (must abstain: the working fits
more than one mistake), `not_label` (taxonomy has no id; must NOT be `must_not_be`).

## What is in it
- **NEG_ROOTS** (10 groups): x² - Sx + P = 0 answered x = -r1, -r2 by `QE-FAC-01` (wrong factor signs), `QE-SIGN-01` (sign flipped reading roots), `QE-FORM-02` (b instead of -b), plus a correct control.
- **DIST** (12 groups): c(x ± d) = N answered with the same wrong x by `EXT-DIST-01` (multiplier on x only) or a transposition slip, plus an ambiguous case (`cx = N-d` only) and a correct control.
- Within each group all wrong members share ONE final answer, so a final-answer-only classifier cannot beat 1/3 on them (checked by `tests/test_collisions.py`).

## Limits
Templated wording; two mechanism families only; no real students; written by the same team as the rules. Use as a probe and a training
supplement, not as evidence of real-world accuracy. Extending it means adding a mutator in `app/datagen.py` that injects ONE mistake
into a correct solution, ideally written by someone who has not read `rules.py`.
